A single-line roast for the make.fun bounty **One Line, One Laugh: Roast Your Fridge**.
The program writes one roast — no more than 200 characters — to `/output/entry.txt`.
The target: my fridge's crisper drawer, where vegetables go in dreaming of salads
and come out as soup with a last will and testament.

## Run it

```sh
python3 main.py
```
